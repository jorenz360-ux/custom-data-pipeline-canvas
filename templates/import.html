Import mapping from an existing Excel gradebook

Upload any course's gradebook workbook (doesn't have to be this exact template -- works best on sheets with a "STUDENTS" header and section headers like ATTENDANCE / Activities / Quiz / Performance Task / Exam). The app will scan its structure, guess which columns are raw score inputs, and try to match each one to an already-synced Canvas assignment.
